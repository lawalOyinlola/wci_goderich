# Project Instructions

## Content style

- **Never use em dashes (—)** in user-facing content: page copy, descriptions, toasts, dialogs,
  alert/aria text, button labels, metadata titles/descriptions, etc. Rewrite with a period, comma,
  colon, or a connecting word instead. This does not apply to code comments.
- Exception: direct scripture quotations (e.g. `lib/constants/prayer.ts`) keep the source
  translation's exact punctuation, em dashes included. Do not edit quoted Bible text for style.
- Keep alerts, toasts, and dialog copy short. State the one thing the user needs to know and the
  one decision they need to make; do not restate context they already saw on the form.
